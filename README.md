# 《安林斯济慈院之谜》—— TRPG 叙事模组设计

一个基于 COC 7版规则，独立设计的现代英伦悬疑跑团模组。核心设计聚焦于“碎片化线索拼凑真相”与“多层容错Boss战”。

- **PDF文档下载**：[点击下载完整版设计文档](https://morgen336.github.io/anlins-demo/design_document.pdf)

 🧩 核心设计亮点
- **非线性的线索网络**：4条调查路线，任意顺序探索均可拼出真相，保证推理的严整性。
- **多层Boss递进机制**：从恶魔之子（莉莉）到深层恶魔（母亲），触发隐藏NPC（安娜）的容错与多结局设计。
- **情感驱动机制**：不依赖NPC发布任务，以“反常感”驱动玩家内驱力。
